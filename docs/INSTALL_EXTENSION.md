# התקנת התוסף — Mitmachim Draft Sync

מדריך התקנה שלב‑אחר‑שלב לתוסף ה‑Chrome (טעינה כ‑"unpacked", כלומר תיקייה לא‑ארוזה).
המדריך מניח שכבר הקמתם והרצתם שרת API פרטי (ראו `docs/DEPLOY.md`), או שיש לכם כתובת שרת מוכנה.

> כל הפקודות, הנתיבים וה‑URL‑ים נשארים באנגלית בתוך בלוקי קוד. שאר ההסבר בעברית.

---

## דרישות מקדימות

- **Node.js גרסה 20 ומעלה** (נבדק על Node 24). בדיקה:

  ```bash
  node --version
  ```

- דפדפן מבוסס Chromium: **Google Chrome**, **Microsoft Edge**, **Brave** וכדומה (Manifest V3).
- כתובת של שרת API פעיל. אם עדיין אין לכם — בברירת המחדל התוסף מצביע על `https://drafts-api.example.com` (placeholder), ותצטרכו להחליף אותה (ראו "שלב 6" ו"שינוי כתובת ברירת המחדל המהודרת").

## שלב 1 — בניית התוסף

מתוך **שורש הריפו** (repo root):

```
C:\Users\Administrator.pcstu-1045\Documents\DraftSync
```

הריצו:

```bash
npm install
npm run build:extension
```

- `npm install` מתקין את התלויות לכל ה‑workspaces (פעם אחת בלבד, או אחרי עדכון תלויות).
- `npm run build:extension` מבצע **type-check** (`tsc --noEmit`) ואז **bundle** עם esbuild.

הפלט נכתב לתיקייה:

```
extension\dist
```

תיקיית `extension\dist` מכילה את כל מה שהדפדפן צריך: `manifest.json`, `background.js`, `content.js`, `popup.html`, `popup.css`, `popup.js`, תיקיית `icons` ו‑sourcemaps. **זו התיקייה שתטענו לדפדפן** — לא `extension/src` ולא שורש הריפו.

> אם הבנייה נכשלת ב‑type-check — תקנו את שגיאות ה‑TypeScript לפני שממשיכים; ללא בנייה תקינה אין `dist` שלם לטעינה.

## שלב 6 — פתיחת הפופ‑אפ והגדרת כתובת השרת

לחצו על אייקון התוסף בסרגל הכלים כדי לפתוח את הפופ‑אפ (ממשק בעברית, RTL).
בפתיחה הראשונה תראו את מסך **"לא מחובר"**, ובראש החלון תווית סטטוס: **בודק…** ואז **לא מחובר**.

### הגדרת כתובת ה‑API

1. בתחתית המסך, פתחו את האזור **"הגדרות מתקדמות"** (לחיצה על הכותרת המתקפלת).
2. בשדה **"כתובת שרת ה‑API"** הזינו את כתובת השרת שלכם, לדוגמה:

   ```
   https://drafts-api.example.com
   ```

   החליפו ב‑URL האמיתי של השרת שלכם (כולל `https://`).
3. לחצו **"שמור כתובת"**.

#### בקשת הרשאת גישה בזמן ריצה (runtime host permission)

אם הזנתם כתובת **שאינה** ברירת המחדל המהודרת לתוך ה‑`manifest.json`, הדפדפן יציג **בקשת הרשאה קופצת** לגישה לאותו host (התוסף מבקש זאת אוטומטית דרך `chrome.permissions.request`, מתוך ההרשאה ה‑optional `https://*/*` שמוצהרת ב‑manifest).

- בחלון שמופיע, אשרו **Allow** / **אפשר** את הגישה לכתובת השרת.
- אם תסרבו, תופיע ההודעה: **"נדרשת הרשאת גישה לכתובת השרת כדי להמשיך."** — בלי ההרשאה התוסף לא יוכל לדבר עם השרת.

> אותה בקשת הרשאה תופיע גם בלחיצה על **"צור קוד סנכרון חדש"** או **"התחבר"** אם עוד לא אישרתם את ה‑host — הפעולה דואגת לכך לבד.

## שלב 7 — קוד סנכרון: יצירה חדשה או הדבקת קוד קיים

קוד הסנכרון הוא מפתח ההצפנה‑ואימות שלכם. הוא בפורמט `MTD-XXXX-XXXX-XXXX`.
**השרת לעולם לא מאחסן אותו כטקסט גלוי** — ההצפנה מתבצעת אצלכם בדפדפן. שמרו עליו.

### אפשרות א' — יצירת קוד חדש (מכשיר ראשון)

1. (אופציונלי) מלאו **"שם המכשיר (לזיהוי בלבד)"**, למשל `מחשב בית`. זה רק לזיהוי המכשיר ברשימת הטיוטות.
2. לחצו **"צור קוד סנכרון חדש"**.
3. אם נדרש — אשרו את בקשת הרשאת ה‑host (ראו שלב 6).
4. תיפתח חלונית עם הקוד שלכם, למשל:

   ```
   MTD-7QH2-K9MP-4VTX
   ```

   > ⚠️ **הקוד מוצג פעם אחת בלבד ולא ניתן לשחזר אותו.** העתיקו ושמרו אותו במקום בטוח (מנהל סיסמאות וכד'). מי שמחזיק בקוד יכול לקרוא את כל הטיוטות שלכם.

5. לאחר האישור המסך יעבור למצב **"מחובר ✓"**, והקוד יוצג (מוסתר חלקית) עם כפתורי **"העתק קוד"** ו‑**"הצג"**.

### אפשרות ב' — הדבקת קוד קיים (מכשיר נוסף)

אם כבר יש לכם קוד ממכשיר אחר:

1. (אופציונלי) מלאו **"שם המכשיר"** (למשל `לפטופ עבודה`).
2. בשדה **"הדבק קוד סנכרון קיים"** הדביקו את הקוד בפורמט `MTD-XXXX-XXXX-XXXX`.
3. לחצו **"התחבר"**.
4. אם נדרש — אשרו את בקשת הרשאת ה‑host.

אם הקוד שגוי תופיע ההודעה **"קוד הסנכרון שגוי."** או **"ההתחברות נכשלה. ודאו שהקוד נכון."**.
בהצלחה — המסך עובר ל‑**"מחובר ✓"**, ותחת **"טיוטות אחרונות"** יוצגו הטיוטות הקיימות שלכם מהשרת.

## שלב 8 — בדיקה בפורום מתמחים

עכשיו נוודא שהסנכרון אכן עובד מול הפורום.

1. פתחו לשונית חדשה ונווטו אל:

   ```
   https://mitmachim.top/
   ```

2. פתחו **עורך (composer)** באחת מהדרכים:
   - **נושא חדש** (New topic),
   - **תגובה** (Reply) לנושא קיים,
   - או **עריכה** (Edit) של פוסט שכתבתם.
3. התחילו **להקליד** כותרת/תוכן.
4. בתוך העורך תופיע **תווית סטטוס קטנה** (status pill) של התוסף. שימו לב לרצף המצבים:

   | תווית | משמעות |
   |---|---|
   | `טיוטה מסונכרנת` | מצב ראשוני, ממתין לשינוי |
   | `שומר...` | נשלח כעת לשרת |
   | **`נשמר`** | ✅ נשמר בהצלחה (אחרי כמה שניות ישתנה ל‑`נשמר לפני N שניות/דקות`) |
   | `אין חיבור - נשמר מקומית` | אין רשת — נשמר בתור המקומי וייסנכרן אוטומטית |
   | `שגיאה בסנכרון` | בעיה — בדקו כתובת שרת/חיבור |
   | `נמצאה גרסה חדשה יותר בשרת` | קיימת גרסה עדכנית יותר במכשיר אחר |

   הופעת **`נשמר`** מאשרת שהזרימה המלאה עובדת: התוכן הוצפן בדפדפן, נשלח לשרת ונקלט.

   > יש השהיית debounce קצרה (כ‑1.5 שניות) אחרי ההקלדה האחרונה לפני השליחה — זה תקין; `שומר...` יופיע ואז `נשמר`.

5. לאימות נוסף: פתחו שוב את הפופ‑אפ של התוסף — תחת **"טיוטות אחרונות"** אמורה להופיע הטיוטה שזה עתה כתבתם, עם הזמן ושם המכשיר. אפשר גם **"סנכרן עכשיו"** כדי לאלץ שליחה מיידית של התור.

> פרטיות: התסריט בעמוד הפורום **קורא רק את טקסט הכותרת/התוכן בעורך**. הוא אינו ניגש לעוגיות, ל‑localStorage, לפרטי ההתחברות לפורום, ואינו קורא ל‑API של הפורום.

## עדכון התוסף אחרי שינוי בקוד

בכל פעם ששיניתם קוד מקור של התוסף (תחת `extension/src`, `manifest.json` וכו'), צריך **לבנות מחדש ואז לרענן** את התוסף בדפדפן:

1. בנו מחדש מתוך שורש הריפו:

   ```bash
   npm run build:extension
   ```

   או, לפיתוח מתמשך עם בנייה אוטומטית בכל שמירת קובץ:

   ```bash
   npm run watch:extension
   ```

2. עברו ל‑`chrome://extensions` ולחצו על כפתור **הרענון/Reload** (סמל החץ המעגלי ⟳) שעל כרטיס התוסף **Mitmachim Draft Sync**.
   - לחלופין, אפשר ללחוץ על **Update** הכללי בראש העמוד (טוען מחדש את כל התוספים הלא‑ארוזים).
3. אם שיניתם את ה‑`content.js` או את העורך — **רעננו גם את לשונית הפורום** (`mitmachim.top`) כדי שהתסריט החדש ייטען.

> אין צורך להסיר ולהתקין מחדש את התוסף; הקוד שלכם (קוד הסנכרון, הטוקן, ההגדרות) שמור ב‑`chrome.storage.local` ונשמר בין רענונים. הסרה מלאה של התוסף **כן** תמחק אותו.

## שינוי כתובת ברירת המחדל המהודרת (DEFAULT_API_URL)

הגדרת הכתובת בשדה "מתקדם" בפופ‑אפ מספיקה לרוב המשתמשים ונשמרת ב‑`chrome.storage.local`.
אם אתם רוצים שכתובת השרת שלכם תהיה **ברירת המחדל המהודרת** (לדוגמה כדי לחלק את התוסף מוכן לשימוש), ערכו שני קבצים ואז בנו מחדש:

1. **`extension/src/config.ts`** — שנו את הקבוע:

   ```ts
   export const DEFAULT_API_URL = 'https://drafts-api.example.com';
   ```

   ל‑URL האמיתי של השרת שלכם, למשל `https://drafts.example.org`.

2. **`extension/manifest.json`** — עדכנו את `host_permissions` כך שיכלול את אותו host (כדי שלא תידרש בקשת הרשאה בזמן ריצה):

   ```json
   "host_permissions": [
     "https://mitmachim.top/*",
     "https://drafts-api.example.com/*"
   ]
   ```

   החליפו את השורה השנייה ב‑host שלכם, למשל `"https://drafts.example.org/*"`.

3. בנו מחדש וטענו מחדש:

   ```bash
   npm run build:extension
   ```

   ואז כפתור **Reload** ב‑`chrome://extensions` (ראו "עדכון התוסף").

> שימו לב: `host_permissions` חייב להיות **origin מדויק** עם `/*` בסוף (למשל `https://drafts.example.org/*`). אם הכתובת ב‑`config.ts` וב‑`manifest.json` לא תואמות — תוצג בקשת הרשאת host בזמן ריצה כשמתחברים, וזה תקין.

## פתרון תקלות מהיר

- **תווית הסטטוס לא מופיעה בעורך** — ודאו שאתם ב‑`https://mitmachim.top/*`, שהעורך באמת פתוח, ושרעננתם את הלשונית אחרי בנייה. אם הפורום שינה את ה‑DOM, מעדכנים את הסלקטורים בקובץ `extension/src/dom/selectors.ts` ובונים מחדש.
- **`שגיאה בסנכרון` / יצירת קוד נכשלת** — בדקו שכתובת ה‑API נכונה ונגישה (נסו `GET /health` בדפדפן), ושאישרתם את הרשאת ה‑host.
- **לא בטוחים מה קורה** — בפופ‑אפ, במסך "מחובר", סמנו **"מצב דיבוג (console logs)"**. הלוגים מסומנים בקידומת `[MDS]` ב‑console של העמוד/ה‑service worker, ואינם מכילים את טקסט הטיוטה המלא.
- **לצפייה ב‑console של ה‑service worker** — ב‑`chrome://extensions`, על כרטיס התוסף, לחצו על **service worker** / **Inspect views**.

## סיכום מהיר (TL;DR)

```bash
# 1. בנייה
npm install
npm run build:extension          # פלט: extension/dist

# 2. בדפדפן
#    chrome://extensions  ->  Developer mode (ON)  ->  Load unpacked  ->  בחרו extension/dist
#    הצמידו (Pin) את התוסף

# 3. בפופ‑אפ
#    הגדרות מתקדמות -> כתובת שרת ה‑API -> שמור (אשרו בקשת הרשאת host)
#    "צור קוד סנכרון חדש" (ושמרו את הקוד!)  או  הדביקו קוד קיים -> "התחבר"

# 4. בדיקה
#    https://mitmachim.top  ->  פתחו עורך  ->  הקלידו  ->  ודאו "נשמר"

# 5. אחרי שינוי קוד
npm run build:extension          # או npm run watch:extension
#    chrome://extensions -> כפתור Reload (⟳) על כרטיס התוסף
```
